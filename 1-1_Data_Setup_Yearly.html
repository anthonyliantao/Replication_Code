处理年份数据

0. 简介

本笔记基于 1-1_Data_Setup_Yearly.R 脚本，详解其数据处理逻辑:

原脚本的处理逻辑：

  • 读取原始 CPS-ASEC 职业流动数据；
  • 合并细分类职业标签（如教师与助教）；
  • 排除 NEC（未另分类）类别；
  • 生成按年分组的职业流动数据与权重。

本笔记的修改：

  • 生成 fake data 以支持继续操作
  • 将部分重要操作的 data.frame 语法改为了熟悉的 tidyverse 语法
  • 增加了文字解释

2. 读取数据

本脚本依赖根据完整的CPS-ASEC 职业流动数据，以及男女分样本。虽然原始数据暂时不可得，但根据 README 中的描述，我们可以推断出数据文件 edges_67to15ASEC_dropimp_primeage.dta 的结构。

2.1. 数据简介

  • 数据来源：CPS-ASEC 1975–2014 样本
  • 样本范围：25–55 岁就业者
  • 过滤条件：排除了职业信息为“插补值”（imputed occupation）的个体
  • 单位：每条记录是一笔职业转移（从 occ1 → occ2）

2.2. 字段结构

变量名 类型 含义
occ1 character 转出职业（起点）职业名称
occ2 character 转入职业（终点）职业名称
year_begin integer 转移的起始年份（通常是受访年份 - 1）

将清洗后的数据保存为四个主要文件：

  1. dat_FullSamp_FullOccs.csv
    • 包含全样本（FullSamp）中所有职业类别的原始转移数据（未聚合）。
    • 每一行为一条职业转移记录，包含起始职业（occ1）、目标职业（occ2）和对应年份（int_year）。
  2. dat_FullSamp_agg_FullOccs.csv
    • 对全样本职业转移数据按职业对和年份聚合后的数据。
    • 每条记录为某起始职业转移到某目标职业在某年份发生的次数（用 .N 计数）。
  3. dat_FullSamp_NoNEC.csv
    • 从全样本中排除了 NEC（未具体分类职业）类别后，保留的原始转移数据（未聚合）。
    • 便于排除不明确职业对后，进行更精确的职业流动分析。
  4. dat_FullSamp_agg_NoNEC.csv
    • 排除 NEC 后的职业转移数据聚合版本，统计每对职业在各年份的转移次数。

5. 生成标准化年份权重

# 权重标准化的基准年份
w_stand_year = 1989

# 含 NEC 的权重
w_year <- dat %>%
  count(int_year) %>%
  mutate(
    n_stand = n[int_year == w_stand_year],
    obs_weights = n_stand / n
  ) %>%
  select(-n)  # 去掉样本计数列

fwrite(w_year, here("data", paste0("obs_weights_", s_spec, "_FullOccs.csv")))

# 不含 NEC 的权重
w_year_nonec <- nonec_dat %>%
  count(int_year) %>%
  mutate(
    n_stand = n[int_year == w_stand_year],
    obs_weights = n_stand / n
  ) %>%
  select(-n)

fwrite(w_year_nonec, here("data", paste0("obs_weights_", s_spec, "_NoNEC.csv")))

生成权重，对不同年份的样本规模进行标准化，确保基准年份（1989）的观察值数为参考值，其他年份根据样本大小进行调整。

  • 含 NEC 权重：基于全部职业类别的样本；
  • 不含 NEC 权重：剔除未具体分类职业后的样本。

6. 筛选出稳定职业

自定义函数：get_missing_pattern()

查看完整代码 
#' 获取每个职业在不同时间窗口中的缺失模式
#' 
#' @param dat 一个 data.table 数据对象，必须包含列 occ1, occ2, int_year（职业转移数据）
#' @param w_size 滑动窗口大小（可取 1, 3, 5）
#' @param include_isolates 是否保留自环或孤立职业（默认 FALSE，即去除 occ1 == occ2 的转移）
#' @return 返回一个 data.table，列出每个职业在每个年份的出现情况以及缺失模式
get_missing_pattern = function(
    dat, 
    w_size = c(1, 3, 5),
    include_isolates = FALSE) 
{
    # 检查输入数据是否包含必需的列
    if (!all(c("occ1", "occ2", "int_year") %in% names(dat)))
        stop("dat has to contain the columns occ1, occ2, and int_year")
    
    # 检查 w_size 是否有效
    if (!all(w_size %in% c(1, 3, 5)))
        stop("w_size has to be a subset of c(1, 3, 5)")
    
    # 如果不保留孤立职业（自环），则去除 occ1 == occ2 的记录
    if (!include_isolates) 
        dat = dat[occ1 != occ2]
    
    # 获取所有出现过的职业（无重复）
    occs  = dat[, unique(c(occ1, occ2))]

    # 获取所有年份并转为字符向量（便于作为列名）
    y_char = paste0(dat[, sort(unique(int_year))])
    
    # 统计每个职业在哪些年份中出现过（按 int_year 分组后展开）
    m_dat = dat[
        , .(occ_label = unique(c(occ1, occ2))), by = int_year
    ] %>%
        dcast(occ_label ~ int_year, value.var = "int_year")
    
    # 将出现记录转为 1（出现）/0（缺失）
    m_dat[
        , 
        (y_char) := lapply(.SD, function(w) as.numeric(!is.na(w))), 
        .SDcols = y_char
    ][
        ,
        # 计算每个职业缺失的年份数量
        n_miss := length(y_char) - rowSums(.SD), 
        .SDcols = y_char
    ]
    
    # 将每个职业的年份出现情况合并为一个字符串（用于匹配缺失模式）
    m_dat[
        , m_pattern := apply(m_dat[, y_char, with = F],
                             1L, 
                             paste0, 
                             collapse = "")
    ]
    
    # 遍历每个窗口长度（w_size），统计在该窗口大小下缺失的连续“0”片段数
    
    for (w in w_size) {
        
        m_dat[, `:=`
            (
                paste0("m_count_win_", w),
                stringr::str_count(
                    m_pattern, 
                    # 匹配连续 w 个 0 的字符串
                    paste0(rep("0", w), collapse="")
                )
            )
        ]
        
    }
    
    # 返回结果表格（每行一个职业，附带各窗口下的缺失统计
    return(m_dat)
    
}
# 读取不含 NEC 的聚合转移数据
nonec_dat = fread(here("data", "dat_FullSamp_agg_NoNEC.csv"))

# 获取职业在各个 5 年滑动窗口中是否缺失的模式
m_pat = get_missing_pattern(
    dat = nonec_dat, 
    w_size = 5,
    include_isolates = FALSE)

datatable(
  head(m_pat),
  options = list(dom = 't')
)

🔹 m_pattern：年份出现模式字符串

  • 某个职业在各年份中是否出现，1（出现）和 0（缺失）组成的二进制字符串；

🔹 m_count_win_{w}：连续缺失窗口计数

  • 统计该职业在整个时间序列中，出现了多少次“连续5年都未出现”的情况；
  • 对于 m_pattern 10000011000001，值为2
# 选出在所有 5 年窗口中都未缺失的职业
occ_5 = m_pat[m_count_win_5 == 0]$occ_label

# 从原始数据中过滤只保留这些完整职业的转移数据

7. 建立职业名称映射表

dict = read_csv(here("helper", "occ_dictionary.csv")) %>%
    data.table

# 确保职业名称是字符型，避免后续合并出错
dict = dict[, occ_label := as.character(occ_label)]

# 从分析数据中提取实际出现的职业名称（occ1/occ2）
# 赋予一个自增的职业 ID
nonec_dat[
    , .(occ_label = unique(c(occ1, occ2)))
][
    , occ_id := .I
]

# 将官方字典（含 OCC1990 编码）与实际出现职业名称合并
dict = dict %>%
    merge(
        nonec_dat[
            , .(occ_label = unique(c(occ1, occ2)))
        ][
            , occ_id := .I
        ],
        by = "occ_label",
        all.y = TRUE
    ) %>%
    setnames("occ_numeric", "occ_1990")

# 检查完整性
# 是否有ID缺口
if (max(dict$occ_id) != nrow(dict))
    stop("some occ_ids are missing")
# 是否所有出现的职业都能匹配到字典
if (nrow(dict) != length(nonec_dat[, unique(c(occ1, occ2))]))
    stop("some occupations in the dataset are not in the dictionary")

# 保存字典
fwrite(dict, here("data", "labmap_NoNEC.csv"))

datatable(
  dict
